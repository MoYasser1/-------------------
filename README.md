# موقع مكتب عبدالله الأحمد للمحاماة والاستشارات القانونية – دولة الكويت
### Single Page Lawyer Profile Website (Minimal Luxury)

موقع تعريفي رسمي متكامل من صفحة واحدة مصمم خصيصاً للأستاذ **عبدالله الأحمد** – مكتب عبدالله الأحمد للمحاماة والاستشارات القانونية بدولة الكويت، وفق أرقى معايير الفخامة الهادئة (Minimal Luxury) مع التركيز على بناء الثقة والسرعة والتحويل المباشر للتواصل عبر **WhatsApp**.

---

## 🏛️ الهوية البصرية والتصميم
- **اللون الأساسي:** العنابي الداكن Burgundy (`#4A1525` / `#3E0F1E`).
- **اللون الثانوي:** الأحمر القريب من الهوية (`#73223B` / `#8B263E`).
- **الخلفيات:** درجات الأبيض الدافئ والبيج الفاتح (`#FAF7F2` و `#F4EFEB`).
- **اللون المميز:** الذهبي الهادئ (`#C6A664`) لإبراز الشعار والأطر الراقية.
- **الخطوط:** خط `Tajawal` مع خط `IBM Plex Sans Arabic` لراحة القراءة بالعربية.
- **الاتجاه:** RTL بالكامل مع تباين لوني مدروس وفق معايير إمكانية الوصول (Accessibility).

## 📸 إضافة أو تغيير صورة المحامي
1. ضع الصورة الشخصية للمحامي داخل المجلد:
   `assets/images/`
2. سمِّ الملف:
   `lawyer.jpg` (أو يمكنك استخدام أي صيغة أخرى وتعديل المسار في `index.html`).
3. تم ضبط إطار الصورة بتقنية `object-fit: cover` مع `object-position: center top` ليحافظ على ملامح الوجه والأبعاد الطبيعية 100% دون أي تشويه أو تمدد.

## ⚖️ تفعيل قسم الخدمات القانونية
التزاماً بتوجيهاتك بعدم اختراع أية تخصصات غير مؤكدة:
- قسم الخدمات القانونية **مخفي افتراضياً** ولن يظهر في الصفحة أو شريط التنقل.
- عند رغبتك في تفعيله بالخدمات المؤكدة، افتح ملف `js/config.js` وقم بضبط:
  ```javascript
  showServicesSection: true,
  services: [
    {
      id: "litigation",
      title: "التمثيل القضائي والترافع",
      description: "تمثيل الموكلين ومباشرة الدعاوى أمام المحاكم الكويتية."
    },
    // أضف أي خدمات إضافية هنا...
  ]
  ```
  وسيظهر القسم ورابطه في القائمة تلقائياً وفوراً.

## 🚀 تشغيل الموقع محلياً
يمكن فتح ملف `index.html` في أي متصفح مباشرة، أو تشغيل خادم محلي:
```bash
# باستخدام Node.js
npm start

# أو باستخدام Python
python -m http.server 3000
```
ثم فتح المتصفح على: `http://localhost:3000`
